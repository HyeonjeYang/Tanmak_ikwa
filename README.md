# 수리결계

적이 함수로 나오는 탄막 슈팅 게임입니다. 미분 연산자를 쏴서 함수를 0으로 만들면 적이 사라집니다. [index.html](index.html) 파일을 최신 데스크톱 브라우저에서 열면 바로 플레이할 수 있습니다. 게임에는 외부 에셋·라이브러리·서버가 필요하지 않습니다.

## 게임 시작

시작 화면에서 **Easy / Normal / Hard / Insane** 중 하나를 고릅니다. 기본값 Easy입니다. 난이도가 높아질수록 적탄 속도와 밀도, 발사 빈도, 보스 HP가 증가합니다. v2에서 네 난이도 모두 탄속·밀도·발사 빈도를 약 10~15% 올렸습니다. 네 난이도 모두 잔기 3개로 시작합니다. Easy는 봄 4개, Normal과 Hard는 3개, Insane은 2개로 시작합니다.

잔기 3개를 다 쓴 뒤 **이어하기** 또는 **끝내기**도 고를 수 있습니다. 이어하기는 현재 필드나 보스의 진행 상태와 점수를 유지하고 잔기 3개 및 일부 봄을 받아 재개합니다. 끝내기를 고르면 게임 오버가 됩니다. 기본값은 이어하기입니다.

세 장은 각각 **일반 필드전 → 보스 스펠전** 순서로 진행합니다. 필드의 남은 시간이 0이 되면 보스가 나타납니다. 보스 HP를 다 깎거나 스펠 제한 시간이 끝나면 다음 장으로 넘어갑니다. 스펠 획득 보너스는 그 스펠을 피탄·봄 없이 시간 안에 격파해야 받습니다.

| 키 | 동작 |
| --- | --- |
| 방향키 | 이동. 60Hz 기준 프레임당 5px |
| Shift | 저속 이동. 프레임당 2px, 반경 3px 히트박스 표시. 장비마다 발사 방식도 바뀝니다 |
| Z | 현재 장비 발사 |
| C | 장비 교체. d/dx → ∂/∂y → ∇ 순서 |
| 1 / 2 / 3 | 장비 바로 고르기 |
| X | 봄 「Q.E.D.」. 2초 무적, 화면의 탄을 밀어내며 점수화 |
| V | 「정지점」. 반경 160px 안의 적탄을 2초간 정지. 재사용 대기시간 14초 |
| P / Esc | 일시정지·재개 |
| M | 합성 효과음 켜기·끄기 |
| Enter / Z | 시작·재시작·이어하기 |

## 장비

| 장비 | 고속 | 저속 (Shift) | 제약 |
| --- | --- | --- | --- |
| `d/dx` 미분탄 | 5갈래 확산 | 3줄 집중 | 없음 |
| `∂/∂y` 편미분 | 앞쪽 230px 부채꼴 | 화면 끝까지 관통 레이저 | 쏘는 동안 과열 게이지가 찹니다. 다 차면 1.5초 동안 쓸 수 없습니다 |
| `∇` 기울기 | 호밍 빔 8발 | 레이저 유도탄 | 호밍 빔은 4초 재사용 대기. 대기 중에는 약한 직선탄만 나갑니다 |

레이저 유도탄은 플레이어 바로 위로 조준 레이저를 쏩니다. 레이저에 닿은 첫 대상이 0.25초 동안 계속 닿아 있으면 고정(`∇f`)되고, 그때부터 유도탄이 그 대상을 쫓습니다. 대상이 레이저에서 벗어나도 0.4초 동안은 고정이 유지됩니다.

## 연산 규칙

필드의 일반 적은 다항식 `xⁿ` 또는 지수함수 `eˣ`입니다.

| 대상 | `d/dx`, `∇` | `∂/∂y` |
| --- | --- | --- |
| 다항식 `a·xⁿ` | 한 층을 깰 때마다 한 번 미분됩니다. `x³ → 3x² → 6x → 6 → 0` | 남은 식 전체를 한 번에 0으로 만듭니다. 적 주위의 빨간 고리가 남은 HP만큼 차야 합니다 |
| 지수함수 `eˣ` | 통하지 않습니다 (`d/dx eˣ = eˣ`) | 0 |
| 보스 | 100%. 보스 3의 eˣ 상태에서는 통하지 않습니다 | 80%. eˣ 상태에서는 135% |

eˣ를 없애는 방법은 ∂/∂y 하나뿐입니다. d/dx로 미분해서 남은 식이 ∂ 고리보다 작아지면 그 순간 0이 되므로, 두 장비를 섞어 쓰면 더 빨리 끝납니다. 다항식은 남은 차수만큼 칸이 표시됩니다.

필드마다 일정한 순서로 eˣ가 섞여 나옵니다. 필드 1은 6마리 중 1마리, 필드 2는 4마리 중 1마리, 필드 3은 3마리 중 1마리입니다. 다항식의 차수는 필드 1에서 1~2차, 필드 2에서 2~3차, 필드 3에서 3~4차입니다. 차수가 높을수록 탄 갈래가 많고, 3차 이상은 조준탄을 한 발 더 쏩니다. eˣ는 오래 살아 있을수록 재장전이 빨라지고, eˣ가 쏜 탄은 `v₀·e^(1.25t)`로 최대 5배까지 가속합니다.

## 아이템과 그레이즈

아이템은 11~18초 뒤 첫 출현 판정을 하며, 이후 18~30초 간격으로 60% 확률로 나타납니다. 일반 적을 격파할 때는 10% 확률로 추가 드롭됩니다. 방어막이나 이계미분 창이 활성화되어 있거나 줍지 않은 아이템이 화면에 있으면 새 아이템은 나오지 않습니다. 종류도 무작위로 결정되며, 나온 아이템은 플레이어 쪽으로 천천히 움직입니다.

- **∫ 방어막:** 12초 동안 유지되는 방어막. 다음 피탄을 한 번 막습니다. 아이템 없이도 그레이즈를 24번 누적하면 방어막이 만들어집니다.
- **d²/dx² 이계미분 창:** 9초 동안 장비와 관계없이 굵은 관통 미분탄을 쏩니다. 적탄을 지우고 큰 피해를 주지만 eˣ에는 통하지 않습니다 (`d²/dx² eˣ = eˣ`).
- **V 정지점:** `dx/dt = 0`을 적용해 현재 위치 주변의 적탄을 멈춥니다. 발동 순간 근접한 탄도 지웁니다.

그레이즈는 히트박스 바깥 반경 18px 안에 탄이 스칠 때 탄 한 발당 한 번 집계됩니다. 점수 +100과 스파크가 발생합니다. 우측 패널의 ∫ 그래프는 방어막까지 남은 그레이즈를 곡선 아래 넓이로 보여 줍니다.

## 스테이지

| 구간 | 함수 | 실제 공격 |
| --- | --- | --- |
| 필드 1 · 모듈러 | `r = n mod 7` | 일곱 나머지에 따라 일반 적의 위치와 발사각이 반복됩니다. |
| 보스 1 · 극한 | `v = v₀ max(0.15, (d/120)²)`, 몸체 `x³ − 3x` | 플레이어 120px 안의 적탄이 가까워질수록 느려집니다. HP가 4분의 1씩 줄 때마다 몸체가 미분되고(`3x² − 3 → 6x → 6`), 조준탄 갈래가 9 → 7 → 5 → 3으로 줄어듭니다. |
| 필드 2 · 쌍곡함수 | `tanh x = sinh x / cosh x` | 적이 tanh 곡선을 따라 양쪽으로 펼쳐지고 쌍곡함수 부채꼴 탄을 쏩니다. |
| 보스 2 · 미분 | `r = cos(kθ)`, `f′(x) = Aω cos(ωx)`, 몸체 `sin x` | 장미 곡선 탄막과 접선·법선 방향의 예고 레이저가 교대합니다. 몸체는 `sin → cos → −sin → −cos`로 바뀝니다. |
| 필드 3 · 바이어슈트라스 | `W(x) = Σ (.5)ⁿ cos(3ⁿπx)` | 0~4차 파동을 더한 불규칙 궤적과 탄의 발사각을 사용합니다. |
| 보스 3 · 자기장 | `Δθ = q B Δt`, 몸체 `eⁱᶿ` / `eˣ` | 양전하·음전하 탄이 반대로 휘어지고 자기장 부호가 주기적으로 바뀝니다. 12초마다 5초 동안 eˣ 상태가 되어 ∂/∂y만 통하고, 그동안 가속하는 eˣ 탄을 원형으로 뿌립니다. |

보스는 자기 몸체 함수의 그래프로 그려지고, 미분될 때마다 그래프가 다시 그려집니다.

## 화면

모눈종이 위에 잉크로 그린 수학 노트처럼 보이도록 만들었습니다. Glow를 쓰지 않는 대신 모든 탄에 잉크 테두리와 흰 심을 넣어 밝은 바탕에서도 보이게 했습니다. 시작 화면은 시험지 문제 형식이고, 난이도는 빨간 펜 동그라미로 고릅니다.

게임은 `requestAnimationFrame`과 1/60초 고정 간격 시뮬레이션을 사용합니다. 적탄, 샷, 파티클, 일반 적, 아이템, 수식 라벨은 고정 풀로 관리합니다. 모눈 배경은 한 번만 그려 두고 스크롤하며, 같은 색 탄은 묶어 그립니다.

## 검증

Node.js만 있으면 로직 검증을 실행할 수 있습니다.

```sh
node tests/verify.cjs
```

브라우저 검증에는 Playwright와 Chromium이 필요합니다. 게임 실행에는 필요하지 않습니다. 브라우저를 따로 받지 않고 설치된 Edge나 Chrome을 쓰려면 `CHROMIUM_PATH`로 실행 파일 경로를 지정합니다.

```sh
node tests/browser.cjs
CHROMIUM_PATH="C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" node tests/browser.cjs path/to/playwright-core
```
