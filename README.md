# 수리결계

수학 함수가 탄의 궤적과 속도를 정하는 탄막 슈팅 게임입니다. [index.html](index.html) 파일을 최신 데스크톱 브라우저에서 열면 바로 플레이할 수 있습니다. 게임에는 외부 에셋·라이브러리·서버가 필요하지 않습니다.

## 게임 시작

시작 화면에서 **Easy / Normal / Hard / Insane** 중 하나를 고릅니다. 기본값 Easy입니다. 난이도가 높아질수록 적탄 속도와 밀도, 발사 빈도, 보스 HP가 증가합니다. 네 난이도 모두 잔기 3개로 시작합니다. Easy는 봄 4개, Normal과 Hard는 3개, Insane은 2개로 시작합니다.

잔기 3개를 다 쓴 뒤 **이어하기** 또는 **종료**도 고를 수 있습니다. 이어하기는 현재 필드나 보스의 진행 상태와 점수를 유지하고 잔기 3개 및 일부 봄을 받아 재개합니다. 종료를 선택하면 게임 오버가 됩니다. 기본값은 이어하기입니다.

세 장은 각각 **일반 필드전 → 보스 스펠전** 순서로 진행합니다. 필드의 남은 시간이 0이 되면 보스가 나타납니다. 보스 HP를 다 깎거나 스펠 제한 시간이 끝나면 다음 장으로 넘어갑니다. 스펠 획득 보너스는 그 스펠을 피탄·봄 없이 시간 안에 격파해야 받습니다.

| 키 | 동작 |
| --- | --- |
| 방향키 | 이동. 60Hz 기준 프레임당 5px |
| Shift | 정밀 이동. 프레임당 2px, 반경 3px 히트박스 표시 |
| Z | 직선 샷과 유도탄 발사 |
| X | 봄 「공리 선언」. 2초 무적, 화면의 탄을 밀어내며 점수화 |
| C | 「정지점」. 반경 160px 안의 적탄을 2초간 정지. 재사용 대기시간 14초 |
| P / Esc | 일시정지·재개 |
| M | 합성 효과음 켜기·끄기 |
| Enter / Z | 시작·재시작·이어하기 |

## 아이템과 관측

아이템은 11~18초 뒤 첫 출현 판정을 하며, 이후 18~30초 간격으로 60% 확률로 나타납니다. 일반 적을 격파할 때는 10% 확률로 추가 드롭됩니다. 방어막이나 미분의 창이 활성화되어 있거나 줍지 않은 아이템이 화면에 있으면 새 아이템은 나오지 않습니다. 종류도 무작위로 결정되며, 나온 아이템은 플레이어 쪽으로 천천히 움직입니다.

- **∫ 적분 방어막:** 12초 동안 유지되는 방어막. 다음 피탄을 한 번 막습니다. 아이템 없이도 그레이즈를 24번 누적하면 방어막이 만들어집니다.
- **∂ 미분의 창:** 9초 동안 강화 샷을 발사합니다. 창은 적탄을 지우고 보스나 일반 적에게 큰 피해를 줍니다.
- **C 정지점:** `dx/dt = 0`을 적용해 현재 위치 주변의 적탄을 멈춥니다. 발동 순간 근접한 탄도 지웁니다.

그레이즈는 히트박스 바깥 반경 18px 안에 탄이 스칠 때 탄 한 발당 한 번 집계됩니다. 점수 +100과 흰색 스파크가 발생합니다. 우측 패널에 적분 방어막 진행도와 기술 남은 시간을 표시합니다.

## 수학 함수

| 구간 | 함수 | 실제 공격 |
| --- | --- | --- |
| 필드 1 · 모듈러 | `r = n mod 7` | 일곱 나머지에 따라 일반 적의 위치와 발사각이 반복됩니다. |
| 보스 1 · 극한 | `v = v₀ max(0.15, (d/120)²)` | 플레이어 120px 안의 적탄이 가까워질수록 느려집니다. |
| 필드 2 · 쌍곡함수 | `tanh x = sinh x / cosh x` | 적이 tanh 곡선을 따라 양쪽으로 펼쳐지고 쌍곡함수 부채꼴 탄을 쏩니다. |
| 보스 2 · 미분 | `r = cos(kθ)`, `f′(x) = Aω cos(ωx)` | 장미 곡선 탄막과 접선·법선 방향의 예고 레이저가 교대합니다. |
| 필드 3 · 바이어슈트라스 | `W(x) = Σ (.5)ⁿ cos(3ⁿπx)` | 0~4차 파동을 더한 불규칙 궤적과 탄의 발사각을 사용합니다. |
| 보스 3 · 자기장 | `Δθ = q B Δt` | 양전하·음전하 탄이 반대로 휘어지고 자기장 부호가 주기적으로 바뀝니다. |

게임은 `requestAnimationFrame`과 1/60초 고정 간격 시뮬레이션을 사용합니다. 적탄, 샷, 파티클, 일반 적, 아이템은 고정 풀로 관리합니다. Canvas 도형·그라데이션·Glow만 사용하며, 성능을 위해 같은 색 탄은 묶어 그립니다.

## 검증

Node.js만 있으면 로직 검증을 실행할 수 있습니다.

```sh
node tests/verify.cjs
```

브라우저 검증에는 Playwright와 Chromium이 필요합니다. 게임 실행에는 필요하지 않습니다.

```sh
node tests/browser.cjs
```
