# 수리결계

적이 함수로 나오는 탄막 슈팅 게임입니다. 연산자를 쏴서 함수를 0으로 만들면 적이 사라집니다. [index.html](index.html) 파일을 최신 데스크톱 브라우저에서 열면 바로 플레이할 수 있습니다. 게임에는 외부 에셋·라이브러리·서버가 필요하지 않습니다.

## 게임 시작

시작 화면에서 **Easy / Normal / Hard / Insane** 중 하나를 고릅니다. 기본값은 Easy입니다. 난이도가 높아질수록 적탄 속도와 밀도, 발사 빈도, 보스 HP가 증가합니다. 네 난이도 모두 잔기 3개로 시작합니다. Easy는 봄 4개, Normal과 Hard는 3개, Insane은 2개로 시작합니다.

**시작 단원**은 1부터 7까지 고를 수 있습니다. 1단원이 아닌 곳에서 시작하면 연습으로 취급합니다. 그 단원까지 나오는 연산자를 모두 들고 시작하고, 최고 점수는 저장하지 않습니다.

잔기 3개를 다 쓴 뒤 **이어하기** 또는 **끝내기**도 고를 수 있습니다. 이어하기는 현재 필드나 보스의 진행 상태와 점수를 유지하고 잔기 3개 및 일부 봄을 받아 재개합니다. 끝내기를 고르면 게임 오버가 됩니다. 기본값은 이어하기입니다.

일곱 단원은 각각 **일반 필드전 → 보스 스펠전** 순서로 진행합니다. 필드의 남은 시간이 0이 되면 보스가 나타납니다. 보스 HP를 다 깎거나 스펠 제한 시간이 끝나면 다음 단원으로 넘어갑니다. 스펠 획득 보너스는 그 스펠을 피탄·봄 없이 시간 안에 격파해야 받습니다.

## 장비

1–3단원은 처음 세 장비로 풉니다. 4단원부터는 단원을 시작할 때 새 연산자를 하나씩 받고, 받은 연산자를 바로 손에 듭니다.

| 장비 | 받는 때 | 고속 | 저속 (Shift) | 제약 |
| --- | --- | --- | --- | --- |
| `d/dx` 미분탄 | 처음부터 | 5갈래 확산 | 3줄 집중 | 없음 |
| `∂/∂y` 편미분 | 처음부터 | 앞쪽 230px 부채꼴 | 화면 끝까지 관통 레이저 | 쏘는 동안 과열 게이지가 찹니다. 다 차면 1.5초 동안 쓸 수 없습니다 |
| `∇` 기울기 | 처음부터 | 호밍 빔 8발 | 레이저 유도탄 | 호밍 빔은 4초 재사용 대기. 대기 중에는 약한 직선탄만 나갑니다 |
| `∮` 폐곡선 | 4단원 | 직접 움직여 고리를 그립니다. 펜이 지나온 길로 돌아오면 고리가 닫히고, 안쪽에 있는 것에 적용됩니다 | 내 둘레 반지름 64px 원 `C`. 원 안에 든 것을 계속 적분합니다 | 탄을 쏘지 않습니다. 스칼라 함수에는 `∮∇f·dr = 0`이라 아무 일도 없습니다 |
| `A⁻¹` 역행렬 | 5단원 | 행렬 근처에서도 휘지 않는 탄 4줄 | 사영 `P = [1 0; 0 0]`. 앞쪽 상자 안의 적탄에서 세로 성분을 지웁니다. 똑바로 떨어지는 탄은 `ker P`라서 사라집니다 | 사영 게이지는 3초 쓰면 바닥나고, 0.35까지 다시 차야 쓸 수 있습니다 |
| `ℱ` 변환 | 6단원 | 1·3·5배음 진폭으로 흔들리는 파형탄 3줄 | 곧게 나가는 단일 주파수 | 없음 |
| `𝔼` 기댓값 | 7단원 | 몬테카를로 산탄 (각도·속도 무작위) | 표본평균. 오래 쏠수록 퍼짐이 `σ/√n`로 줄어듭니다 | 없음 |

레이저 유도탄은 플레이어 바로 위로 조준 레이저를 쏩니다. 레이저에 닿은 첫 대상이 0.25초 동안 계속 닿아 있으면 고정(`∇f`)되고, 그때부터 유도탄이 그 대상을 쫓습니다. 대상이 레이저에서 벗어나도 0.4초 동안은 고정이 유지됩니다.

`∮` 고리는 펜이 7px마다 남긴 점으로 만듭니다. 12개 넘게 지난 점의 16px 안으로 돌아오면 닫히며, 넓이가 1200px² 이상이어야 합니다. 한 고리로 여러 적을 감싸면 보너스 점수가 붙습니다.

## 연산 규칙

| 대상 | 통하는 것 | 안 통하는 것 |
| --- | --- | --- |
| 다항식 `a·xⁿ` | `d/dx`, `∇`는 한 층을 깰 때마다 한 번 미분 (`x³ → 3x² → 6x → 6 → 0`). `∂/∂y`는 빨간 고리가 남은 식 전체를 덮으면 한 번에 0. `A⁻¹`·`ℱ`·`𝔼`는 절반 피해 | `∮` (`∇f`라서 0) |
| 지수함수 `eˣ` | `∂/∂y`만 | 나머지 전부 (`d/dx eˣ = eˣ`) |
| 벡터장 `F = A(x, y)` (원천·흡수·소용돌이) | `∮`로 감싸면 바로 0 (`∇·F` 또는 `∇×F`가 0이 아니므로). 다른 장비는 40% | 없음 |
| 행렬 `A` | `A⁻¹`은 휘지 않고 150%. 회전·전단처럼 `∇×F`나 `tr A`가 0이 아닌 행렬은 `∮`도 됨 | 다른 탄은 반경 44px 안에서 방향이 `A·d`로 바뀌고 피해도 `|A·d|`배가 됩니다. 고유벡터 방향으로 들어온 탄만 휘지 않습니다. `[0 1; 1 0]`은 대칭이고 대각합이 0이라 `∮ = 0` |
| `sin x` | `ℱ`를 맞으면 두 스펙트럼 선 `δ(ω ± 1)`로 갈라지고, 선은 한 대에 사라짐. `∂/∂y`로도 0 | `d/dx`는 `sin → cos → −sin → −cos → sin`으로 돌기만 함 |
| `e⁻ˣ²` (가우스) | `∂/∂y`만 | `ℱ` (푸리에 변환의 고정점), 미분 |
| `1/(s − 1)` (라플라스 극) | `∮` (유수) | 미분 전부. `ℱ`를 쓰면 `ℒ⁻¹`으로 `eᵗ`가 되어 `∂/∂y`만 통함 |
| `Wₜ` (브라운 운동) | `𝔼` 한 대에 0 (`𝔼[Wₜ] = 0`) | 미분 전부 (어디서도 미분 불가능) |
| `Sₜ` (기하 브라운 운동) | `𝔼` → `eˣ`가 됨 → `∂/∂y` | 미분 전부 |
| `Pois(4)` | `𝔼` → `4x`가 됨 → `d/dx` | 미분 전부 |
| `Geo(.15)` | 아무 장비나 맞을 때마다 시행 한 번 (0.14초에 한 번). 15% 확률로 0. `𝔼`는 상수 7로 바꿈 | 없음 |
| `HG(8, 2)` | 맞을 때마다 카드 8장 중 한 장을 비복원으로 뽑음. 표시된 2장이 다 나오면 0. 최악이어도 8번째에 끝남. `𝔼`는 한 번에 두 장 | 없음 |

eˣ를 없애는 방법은 여전히 ∂/∂y 하나뿐입니다. 적 카드 오른쪽 위의 빨간 글씨는 그 적에게 먼저 써야 할 연산자입니다. 패널의 「약점」 칸에도 지금 필드나 보스에 맞는 요약이 나옵니다.

필드 1–3에서는 일정한 순서로 eˣ가 섞여 나옵니다. 필드 1은 6마리 중 1마리, 필드 2는 4마리 중 1마리, 필드 3은 3마리 중 1마리입니다. 다항식의 차수는 필드 1에서 1~2차, 필드 2에서 2~3차, 필드 3에서 3~4차입니다. 차수가 높을수록 탄 갈래가 많고, 3차 이상은 조준탄을 한 발 더 쏩니다. eˣ는 오래 살아 있을수록 재장전이 빨라지고, eˣ가 쏜 탄은 `v₀·e^(1.25t)`로 최대 5배까지 가속합니다. 필드 4–7은 단원마다 정해진 8마리 순서를 반복합니다.

## 아이템과 그레이즈

아이템은 11~18초 뒤 첫 출현 판정을 하며, 이후 18~30초 간격으로 60% 확률로 나타납니다. 일반 적을 격파할 때는 10% 확률로 추가 드롭됩니다. 방어막이나 이계미분 창이 활성화되어 있거나 줍지 않은 아이템이 화면에 있으면 새 아이템은 나오지 않습니다. 종류도 무작위로 결정되며, 나온 아이템은 플레이어 쪽으로 천천히 움직입니다.

- **∫ 방어막:** 12초 동안 유지되는 방어막. 다음 피탄을 한 번 막습니다. 아이템 없이도 그레이즈를 24번 누적하면 방어막이 만들어집니다.
- **d²/dx² 이계미분 창:** 9초 동안 장비와 관계없이 굵은 관통 미분탄을 쏩니다. 적탄을 지우고 큰 피해를 주지만 eˣ에는 통하지 않습니다 (`d²/dx² eˣ = eˣ`).
- **V 정지점:** `dx/dt = 0`을 적용해 현재 위치 주변의 적탄을 멈춥니다. 발동 순간 근접한 탄도 지웁니다.

그레이즈는 히트박스 바깥 반경 18px 안에 탄이 스칠 때 탄 한 발당 한 번 집계됩니다. 점수 +100과 스파크가 발생합니다. 우측 패널의 ∫ 그래프는 방어막까지 남은 그레이즈를 곡선 아래 넓이로 보여 줍니다.

## 단원

| 단원 | 필드 | 보스 | 보스의 실제 공격과 약점 |
| --- | --- | --- | --- |
| 1 · 극한 | 「나머지의 격자」 `r = n mod 7` | 「엡실론-델타의 감옥」 몸체 `x³ − 3x` | 플레이어 120px 안의 적탄이 `v₀·max(.15, (d/120)²)`로 느려집니다. HP가 4분의 1씩 줄 때마다 몸체가 미분되고(`3x² − 3 → 6x → 6`), 조준탄 갈래가 9 → 7 → 5 → 3으로 줄어듭니다. |
| 2 · 미분 | 「쌍곡의 통로」 `tanh` | 「접선의 폭주」 몸체 `sin x` | 장미 곡선 `r = cos kθ` 탄막과 접선·법선 방향의 예고 레이저가 교대합니다. 몸체는 `sin → cos → −sin → −cos`로 바뀝니다. |
| 3 · 초월 | 「끊기지 않는 파형」 바이어슈트라스 함수 | 「로렌츠 힘과 오일러 나선」 몸체 `eⁱᶿ` / `eˣ` | 양전하·음전하 탄이 `Δθ = qBΔt`로 반대로 휩니다. 12초마다 5초 동안 eˣ 상태가 되어 ∂/∂y만 통하고(135%), 그동안 가속하는 eˣ 탄을 원형으로 뿌립니다. |
| 4 · 벡터해석 | 「발산과 회전」 원천·흡수·소용돌이 | 「발산정리와 스토크스」 `F = (x, y)` / `F = (−y, x)` | 10초마다 가우스와 스토크스가 바뀝니다. 가우스일 때 탄은 `1/r`로 느려지며 껍질처럼 쌓이고, 전하 부호가 바뀌면 보스 쪽으로 되돌아옵니다. `∮`로 감싸면 크기와 상관없이 300. 스토크스일 때 탄은 강체 회전하며 퍼지고, `∮` 피해는 고리 넓이에 비례합니다(80–560). 다른 장비는 50%. |
| 5 · 선형대수 | 「선형변환」 행렬 적 | 「고윳값의 감옥」 `dx/dt = Ax` | 고리 모양 탄이 `x(t) = eᴬᵗ x₀`를 따라 퍼집니다. 4분의 1마다 `A`가 나선(`λ = .3 ± i`), 안장점(`±.7`), 중근 전단, `det A = 0`으로 바뀌고, 실수 고유벡터는 점선으로 그려집니다. 보스 100px 안의 탄은 `A`로 휘므로 `A⁻¹`(140%)만 곧게 닿습니다. 안장점은 대칭·대각합 0이라 `∮ = 0`. 마지막 `det A = 0`에서는 아무것도 휘지 않습니다. |
| 6 · 복소해석 | 「스펙트럼」 sin, 가우스, 라플라스 극 | 「유수정리」 `1/(z² + 1)` → `2z/(z² − 1)` → `1/(z³ − 1)` → `eᶻ/z` | 보스 둘레를 도는 극(×)마다 유수가 적혀 있습니다. `∮` 고리 하나는 안에 든 극의 `2πi·Σ Res`만큼 깎습니다. `1/(z² + 1)`의 두 극을 함께 감싸면 유수가 상쇄되어 0, 극 없이 몸체만 감싸면 코시 정리로 0입니다. 탄은 `f`의 폴랴 벡터장을 따라 극 둘레를 돌거나 흘러나갑니다. 다른 장비는 40%. |
| 7 · 편미분방정식 | 「확률과정」 브라운 운동과 분포들 | 「반응-확산」 `∂u/∂t = DΔu + f(u)` | 화면에 30×32칸 농도 `u`를 풉니다. 4분의 1마다 열방정식(감쇠), 피셔–KPP, 쌍안정(앨런–칸), 이류가 붙은 피셔로 바뀝니다. `u > .55`인 칸에서 탄이 생기지만 플레이어 70px 안에서는 생기지 않습니다. 샷이 지나간 칸, `∂/∂y` 레이저가 닿은 칸, `∮` 고리 안, 원 `C` 안의 `u`가 줄어들고, 봄은 전체를 지웁니다. `ℱ`는 160%. |

보스는 자기 몸체를 그림으로 들고 나옵니다. 그래프(1–3단원, 7단원은 반응항 `f(u)`), 벡터장 화살표(4단원), 단위정사각형의 상과 `Aî`·`Aĵ`(5단원), 정의역 색칠 위상 그림(6단원)이고, 몸체가 바뀔 때마다 다시 그립니다.

## 화면

모눈종이 위에 잉크로 그린 수학 노트처럼 보이도록 만들었습니다. Glow를 쓰지 않는 대신 모든 탄에 잉크 테두리와 흰 심을 넣어 밝은 바탕에서도 보이게 했습니다. 카드와 배너 테두리는 모서리가 조금씩 삐져나오는 손그림 선이고, 적마다 흔들림이 다릅니다. 시작 화면은 시험지 문제 형식이고, 난이도와 시작 단원은 빨간 펜 동그라미로 고릅니다.

캔버스는 논리 좌표 800×700으로 그리되, 실제 픽셀 수는 화면에 보이는 크기 × `devicePixelRatio`를 따릅니다. 배율은 1/20 단위로 맞춰 20px 모눈이 늘 정수 픽셀에 떨어지게 했습니다. 창 크기나 모니터 배율이 바뀌면 다시 계산하므로 125%·150%·200% 배율에서도 선과 글자가 흐려지지 않습니다. 게임 화면은 창 높이에 맞춰 커집니다.

게임은 `requestAnimationFrame`과 1/60초 고정 간격 시뮬레이션을 사용합니다. 적탄, 샷, 파티클, 일반 적, 아이템, 수식 라벨은 고정 풀로 관리합니다. 모눈 배경은 해상도마다 한 번만 그려 두고 스크롤하며, 같은 색 탄은 묶어 그립니다. 반응-확산 농도는 30×32 이미지를 부드럽게 늘려 칠하고, `u = .55` 등고선은 마칭 스퀘어로 따로 그립니다.

## 검증

Node.js만 있으면 로직 검증을 실행할 수 있습니다. 57개 항목이 일곱 단원과 일곱 장비의 규칙을 실제 게임 코드로 확인합니다.

```sh
node tests/verify.cjs
```

브라우저 검증에는 Playwright와 Chromium이 필요합니다. 게임 실행에는 필요하지 않습니다. 브라우저를 따로 받지 않고 설치된 Edge나 Chrome을 쓰려면 `CHROMIUM_PATH`로 실행 파일 경로를 지정합니다. 스크린샷은 `tests/artifacts/`에 저장되며, 2배 해상도로 찍은 `hidpi-field-5.png`도 함께 남습니다.

```sh
node tests/browser.cjs
CHROMIUM_PATH="C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" node tests/browser.cjs path/to/playwright-core
```
